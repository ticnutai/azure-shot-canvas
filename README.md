# אולפן צילום מסך

אפליקציית Windows מקומית לצילום תמונות ולהקלטת מסך באיכות גבוהה. הממשק בעברית והקבצים נשמרים במחשב בלבד.

## יכולות

- צילום מסך, חלון או אזור נבחר ל-PNG.
- צילום עמוד גלילה מודרך עם חיבור חפיפות אוטומטי, עצירה אוטומטית, אזור הצילום האחרון ועד 12 אזורים שמורים.
- הקלטת מסך או חלון ל-WebM וייצוא MP4 אוטומטי כש-FFmpeg זמין.
- הקלטות ארוכות נשמרות במקטעים של עד 30 שניות או 64MB, עם יומן התאוששות ושחזור אוטומטי לאחר הפסקה או קריסה.
- קול מערכת ומיקרופון נשמרים גם כמיקס בווידאו וגם כערוצי AAC נפרדים; FFmpeg מתאים את משך הערוצים ומתקן drift באמצעות resampling אסינכרוני.
- ניטור מצלמה מזהה הפסקת פריימים, מנסה לחבר מחדש את התצוגה וממשיך לשמור את ההקלטה.
- עורך Timeline לא־הרסני: פיצול קליפים, הסרת שתיקות, מעברי Fade, כתוביות נגררות, זום אוטומטי לפי נתיב העכבר וארבעה presets לייצוא MP4.
- אוטומציות לאחר צילום או הקלטה: העתקה, OCR, תיקיית לקוח, עורך, שיתוף ופתיחת תיקייה. פעולות כפולות באותו אירוע מדולגות אוטומטית.
- בחירת איכות: מסמכים, רגיל או תנועה חלקה.
- בחירת אזור מתוך תצוגה מקדימה לפני צילום או הקלטה.
- השהיה, המשך ועצירה של הקלטה.
- ספריית קבצים מקומית ופתיחת תיקיית הפלט.
- מרכז קיצורים מלא עם צירופים, מקש יחיד או לחיצה כפולה; הקיצורים מבוססי מיקום פיזי ולכן עקביים בפריסת מקלדת עברית ואנגלית.
- סרגל מהיר צף מעל כל תוכנה: אוטו־הייד בקצה ימין, שמאל או עליון, פתיחה בלחיצה או בריחוף, הצמדה, תמיכה בריבוי מסכים ושמונה פעולות צילום, הקלטה, שמע וספרייה.
- קיצורי פיתוח: `Ctrl+Shift+R` לרענון מלא ו-`Ctrl+Shift+I` או `F12` לפתיחת כלי המפתחים.
- מרכז כלים מקומי: OCR בעברית ובאנגלית, חיפוש בתוכן, תמלול Whisper וכתוביות SRT.
- דוח איכות מספרי לכל וידאו: FPS, פריימים, רזולוציה, קודקים, סנכרון וציון 0–100.
- סימוני פרקים בהקלטה, צורת גל בעורך הווידאו, הצמדת צילום מעל חלונות ו־Tray.
- שיתוף מקומי פרטי ב־127.0.0.1 עם אסימון אקראי ותפוגה של 30 דקות; אין העלאה לענן.
- עורך תמונות: השחרה חכמה שמאתרת ומשחירה דוא"ל, טלפונים, כרטיסי אשראי, תעודות זהות, כתובות רשת וקישורים (זיהוי מקומי בלבד); זרקור שמחשיך את כל מה שמחוץ לאזור; ייצוא מעוצב לשיתוף עם רקע, ריפוד, פינות מעוגלות וצל.
- כרטיס אחרי צילום (כמו בתוכנות הצילום המובילות): מיד אחרי צילום או הקלטה מופיע מעל כל תוכנה כרטיס עם תמונה מקדימה (ואורך, להקלטה) ופעולות — עריכה, העתקה, הצמדה, תיקייה, מחיקה לסל המיחזור — וגרירה ישירה של הקובץ לתוכנה אחרת. נסגר מעצמו (4/6/10 שניות או לא), נשאר פתוח כשהעכבר עליו, עובד גם כשהסרגל הצף כבוי, ומציג פס של הצילומים האחרונים. בנוי על הסרגל הצף ועל אותן פעולות של האוטומציות — בלי מערכת כפולה.
- תצוגה חיה ניתנת לכיבוי (חוסך מעבד וזיכרון), וחלון האולפן מוסתר מהצילומים כברירת מחדל — בלי "מנהרת מראות" ובלי חלון האולפן בהקלטות מסך מלא.
- הקשחה: רק דפי האפליקציה יכולים להפעיל את התהליך הראשי, רק שלוש הרשאות (מצלמה ומיקרופון, צילום מסך, מסך מלא), פתיחת קבצים רק מתוך הספרייה, והגנות של התוכנה המותקנת מפני הרצה כמריץ סקריפטים והחלפת קבצים.

## מנועים מקומיים וללא כפילויות

האפליקציה אינה מתקינה מנוע חלופי אם כבר קיים מנוע מתאים. היא משתמשת ב־Electron לצילום, ב־FFmpeg/FFprobe הקיימים להמרה ואבחון, ב־Tesseract הקיים ל־OCR ובשרת `chai-transcribe` הקיים ב־`127.0.0.1:3000` לתמלול. החבילה מוסיפה ל־Tesseract רק את קובץ השפה `heb.traineddata` הרשמי; לא עותק נוסף של מנוע OCR. אם מנוע אינו זמין, מרכז הכלים מציג זאת במפורש ואינו מתקין שירות נוסף מאחורי הקלעים.

## מצבי הפעלה

```powershell
npm install
```

| פקודה | מה נפתח |
|---|---|
| `npm run dev` או `npm run localhost` | שרת localhost בלבד, בלי לפתוח חלון |
| `npm run dev:stop` | סגירה מאומתת של שרתי Aurum המקומיים בלבד |
| `npm run localhost:open` | localhost בלבד ופתיחת הדפדפן |
| `npm run electron` או `npm run electron:start` | Electron בלבד מתוך הקבצים המקומיים |
| `npm start` או `npm run electron:dev` | Electron המחובר ל-localhost עם live reload |
| `npm run electron:pack` | תיקיית Electron לא ארוזה ב-`dist/win-unpacked` |
| `npm run electron:dist` או `npm run build` | מתקין Windows מלא |

שרת הפיתוח מאזין כברירת מחדל ב-`http://127.0.0.1:4173`. אם הפורט תפוס הוא מחפש פורט פנוי; אם כבר פועל עליו שרת Aurum תקין הוא משתמש בו ולא יוצר כפילות. ממשק הדפדפן שומר צילומים לתיקיית ההורדות, ואילו Electron משתמש בספרייה המקומית המלאה.

במצב `electron:dev`, שינוי בקובצי הממשק גורם לרענון אוטומטי אמיתי דרך SSE ללא cache. שינוי ב-`main.cjs`, ב-preload או בקוד הראשי מפעיל מחדש את תהליך Electron. `Ctrl+Shift+R` מבצע רענון מלא ידני.

## עיצוב: פריסות, צבעים וערכות

המראה בנוי משלוש שכבות נפרדות שנבחרות בהגדרות ← עיצוב וערכות נושא (או מתפריט ערכות הנושא ← "פריסות וערכות עיצוב"):

- **פריסת החלון** (`data-layout`): למען (המקורית), מקצועי, סריקה ומסמכים, קלאסי, אלגנטי, משרדי, מודרני — מיקום וגודל הסרגלים, צפיפות וגופן.
- **צבעי הפריסה**: לכל פריסה זוג בהיר/כהה מותאם, או השארת ערכת הצבעים האישית.
- **ערכת עיצוב** (`data-kit`): לפי הפריסה, קומפקטי, אריחים, רשימה, אייקונים, מינימלי — רק פינות, ריפוד, מסגרות וצללים.
- **גודל תצוגה**: 75%–150% לכל הממשק.

לפני כל שינוי עיצוב: מצלמים בסיס, משנים, ומשווים — 41 צילומים (10 מסכים × 4 מראות + העורך בחלון צר) חייבים להיות זהים לפיקסל, אלא אם השינוי מכוון.

הבחירה נשמרת במחשב ומוחלת לפני הציור הראשון (`src/boot-appearance.js`), כך שאין הבזק של צבע לא נכון. כל הכללים נמצאים ב-`src/app-design.css` ומבוססים על משתנים — פריסה או ערכה חדשה מוסיפות רק ערכי משתנים.

```powershell
node scripts/design-shots.cjs        # צילום כל הפריסות (בהיר/כהה) וכל הערכות אל artifacts/design-shots
node scripts/benchmark.cjs           # מדידת מהירות הפעולות העיקריות אל artifacts/benchmark/latest.json
node scripts/css-dedupe.cjs          # איתור הגדרות עיצוב שלעולם לא חלות (נדרסות בכלל זהה מאוחר יותר); --apply מסיר אותן
npx playwright test -c playwright.visual.config.cjs --update-snapshots   # צילומי בסיס של כל המסכים (נשמרים מקומית)
npx playwright test -c playwright.visual.config.cjs                      # השוואה מדויקת לפיקסל מול הבסיס
```
## בדיקות ובניית מתקין

```powershell
npm test
npm run test:qa
npm run electron:dist
```

`npm run test:qa` מפעיל בדיקות יחידה ובדיקות Playwright מול Electron אמיתי, מודד זמני תגובה, מאמת PNG/MP4 ואודיו באמצעות FFprobe/FFmpeg, וכותב דוחות מספריים אל `artifacts/qa/latest-report.html` ו-`latest-report.json`.

ברירת המחדל לשמירה היא התיקייה `Videos\אולפן צילום מסך` של המשתמש.
